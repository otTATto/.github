# Contribution Guide

Thank you for your interest in my projects!✨ Contributions of any size are very welcome, from fixing a typo to adding a new feature.

This guide applies to all my repositories. If a repository has its own `CONTRIBUTING.md`, follow that one instead.

> [!NOTE]
> You can write issues and pull requests in either English or Japanese.

## Issues

- Before opening an issue, please check whether a similar one already exists, including closed ones.
- Use the issue template and fill in as much as you can.
- **Do not report security vulnerabilities in a public issue.** Follow the instructions in [SECURITY.md](https://github.com/otTATto/.github/blob/main/SECURITY.md) instead.

## Pull Requests

Pull requests are very welcome, even without opening an issue first. For large changes, opening an issue to discuss the idea first can save you time.

1. Fork the repository and create a branch from the default branch.
   - Name the branch `feature/<short-description>` for new features and improvements, or `fix/<short-description>` for bug fixes.
   - e.g. `feature/dark-mode`, `fix/crash-on-startup`
2. Make your changes. Follow the existing code style, and check the repository's README for how to set up and run the project.
   - Write commit messages in the [Conventional Commits 1.0.0](https://www.conventionalcommits.org/en/v1.0.0/) format: `<type>(<optional scope>): <description>`
     - e.g. `feat: Add dark mode`, `fix(editor): Prevent a crash on empty input`
     - Types: `feat`, `fix`, `docs`, `style`, `refactor`, `perf`, `test`, `build`, `ci`, `chore`, `revert`
3. Open a pull request.
   - Write the title in the same Conventional Commits format as commit messages.
   - Fill in the description by following the pull request template.
   - Turn on "Allow edits from maintainers" so that I can make small fixes myself.

Don't worry about getting everything perfect. I'm happy to help you finish your pull request.😉

## Response Time

These are personal projects that I maintain in my spare time, so it may take a while before I reply. Thank you for your patience.

## Code of Conduct

Everyone who participates in my projects is expected to follow the [CODE_OF_CONDUCT.md](https://github.com/otTATto/.github/blob/main/CODE_OF_CONDUCT.md).
